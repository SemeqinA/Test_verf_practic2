# Практическая работа: программа для работы с файлами

Язык: Python. Среда: Visual Studio Code. Интерфейс: консольное меню.

Этот репозиторий содержит программу, тесты, результаты модульного тестирования
и [отчёт в Word](report/Практическая_работа_2_Модульное_тестирование.docx).
Исходные снимки экрана находятся в [report/screenshots](report/screenshots/).
Для быстрого запуска программы выполните `python main.py`, для проверки тестов
следуйте [инструкции](TESTING.md).

Завершён этап модульного тестирования: добавлено 26 тестовых случаев,
найден и исправлен намеренный дефект. Исходный модуль сохранён в `before_fix/`.
Мутационное тестирование и итоговый отчёт относятся к следующим этапам.

## Запуск в VS Code на Windows

1. Открой в VS Code папку `file_practice` через «Файл → Открыть папку».
2. Открой встроенный терминал через «Терминал → Создать терминал».
3. Убедись, что терминал находится в папке с `main.py`.
4. Выполни:

   ```powershell
   python main.py
   ```

   Если команда `python` не находится, попробуй `py main.py`.

Для самой программы нужен Python 3.9 или новее; сторонние библиотеки ей не нужны.
Используются стандартные `shutil` и `pathlib`. Для закреплённых версий тестовых
зависимостей нужен Python 3.10 или новее; проверка выполнена на Python 3.13.7.
Инструкция запуска тестов находится в `TESTING.md`.

## Первый запуск

1. Введи `1` — чтение файла.
2. Введи `example.txt` — программа покажет три строки текста.
3. Введи `4`, затем `example.txt`, затем `example_copy.txt` — появится копия.
4. Введи `2`, затем `notes.txt`, затем любой текст — появится новый файл.
5. Введи `3`, затем `notes.txt`, затем ещё одну строку — текст добавится в конец.
6. Введи `5`, затем `example.txt`, затем `Python` — программа выполнит поиск.
7. Введи `0` для выхода.

Относительные пути отсчитываются от рабочей папки терминала, которую
программа показывает при запуске. Можно вводить абсолютный путь, в том числе
с пробелами и в двойных кавычках. Для копирования указывай полный путь
назначения с именем нового файла, а не только папку.

## Ожидаемое поведение функций

Документация описывает требования к корректной программе. Именно эти
требования проверяет набор модульных тестов.

| Функция | Аргументы | Ожидаемый результат |
|---|---|---|
| `read_file(path)` | Путь к текстовому файлу | Весь текст; для пустого файла — `""` |
| `write_file(path, text)` | Путь и строка | Создаёт файл или полностью заменяет текст; возвращает `None` |
| `append_to_file(path, text)` | Путь и строка | Добавляет строку точно в конец, сохраняя старый текст; возвращает `None` |
| `copy_file(source, destination)` | Пути исходного и нового файлов | Копирует байты исходного файла; возвращает `None` |
| `search_in_file(path, query)` | Путь и искомая непустая строка | Список пар `(номер строки, текст строки)`, номера начинаются с **1** |

### Общие правила

- Чтение, запись, добавление и поиск работают с текстом в UTF-8.
- Копирование работает с любыми файлами, включая двоичные.
- Поиск учитывает регистр: `Python` и `python` — разные запросы.
- Поиск находит подстроку; каждую подходящую строку возвращает один раз.
- Из найденной строки удаляется завершающий перевод строки. Пробелы сохраняются.
- При отсутствии совпадений поиск возвращает `[]`; пустой запрос вызывает `ValueError`.
- `write_file` и `append_to_file` создают отсутствующий файл. Папка должна существовать.
- Функции записи и добавления сами не добавляют перевод строки; меню добавляет `\n`
  после введённого пользователем текста. Если исходный файл не заканчивается
  переводом строки, добавление продолжит его последнюю строку.
- Модуль записи и копирования заменяет существующий файл назначения.
  Меню предварительно спрашивает подтверждение; согласие — слово `да`.
- Чтение, поиск и копирование отсутствующего исходного файла вызывают `FileNotFoundError`.
- Копирование файла в самого себя вызывает `shutil.SameFileError`.
- При недоступном пути, каталоге вместо файла или отсутствии прав функции
  передают соответствующую ошибку файловой системы вызывающему коду.
- Ошибки обработки UTF-8 передаются как `UnicodeError` или его подклассы.
- Меню перехватывает эти ошибки, выводит сообщение и позволяет выбрать другое действие.

## Как устроен код

`with open(...)` открывает файл и автоматически закрывает его после блока.
Режим `r` означает чтение, `w` — запись с заменой, `a` — добавление в конец.
`encoding="utf-8"` позволяет явно задать кодировку текста.

`shutil.copyfile` копирует содержимое файла. Поиск проходит по строкам файла
и проверяет, входит ли запрос в очередную строку.

Основные функции отделены от `input` и `print`: это позволит затем проверять
их с помощью `pytest` без ручного ввода. Блок `if __name__ == "__main__"`
запускает меню только при непосредственном запуске `main.py`.
