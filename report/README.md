# Отчёт по практической работе №2

[Отчёт Word](Практическая_работа_2_Модульное_тестирование.docx) охватывает
разработку программы и модульное тестирование включительно. В нём использованы
скриншоты запуска программы из папки [screenshots](screenshots/) без изменений.
Наглядное [сопоставление результатов тестирования](figures/pytest_before_after.png)
составлено по сохранённым протоколам до и после исправления. Исходный
скриншот запуска pytest сохранён в папке `screenshots` как дополнительный материал.

Результаты тестов и отчёты о покрытии находятся в [results](../results/).
Исходный модуль с учебной ошибкой сохранён в [before_fix](../before_fix/),
исправленный модуль — в корне репозитория.
